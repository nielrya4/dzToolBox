Advanced KDE Options

Override the KDE bandwidth for individual variables. Leave a field blank to use the automatic bandwidth. Values are in each variable's own units (e.g. Ma for Age). Smaller bandwidths give less smoothing. The data range of each variable across the selected samples is shown for reference.

Exclude Grains by Variable

Leave out grains whose value for a variable falls inside any of its ranges (inclusive). Excluded grains are removed from every variable, not just the one they were excluded by. To exclude by age, use Project Settings → Age Range.

To see the automatic bandwidths, run View Empirical KDEs with the KDE Data Table output and open its KDE Parameters tab. The number of points each KDE is discretized over (K) is set in Project Settings → Data. {% endmacro %}
